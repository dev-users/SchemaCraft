# Advanced reports: assessment and improvements

The assessment used the current source, browser workflows and rendered PDFs.

| Finding | Implemented improvement |
| --- | --- |
| Manual IDs made group setup slow and error-prone. | Searchable, paginated profile picker checks the intersection of required schemas and retains selections across pages. |
| Refresh rebuilt inputs and lost typed selections. | Per-template selection state survives refresh and switching during the session. |
| Reports disappeared after restart. | Durable, version-checked drafts with reopen, save-copy and delete controls. Source records remain unchanged. |
| Long editors and native multi-selects were difficult to navigate. | Independent editor scrolling, searchable field checkboxes, starter structures and a template formatting preview. |
| Template references were validated only during later operations. | Live missing/unused indicators plus server validation of referenced schema fields. Uncommitted placeholder edits cannot be silently omitted during template save. |
| Chart analysis was limited to profile values and distributions. | Grouped sum/average/count, sorting, explicit result limits and visible omission notes. |
| Aggregate formatting and matching were limited. | Median, distinct counts, profile counts, numeric precision, units and AND/OR conditions. |
| Every keystroke rebuilt all charts. | Debounced preview rendering, expanded preview mode and clickable outline. |
| Pagination could only be inspected after saving. | Read-only PDF preview generated by the same renderer, plus orientation, typography, header and footer controls. |

Boundaries: this remains a bounded Markdown editor, not a full word processor.
The heading index does not list page numbers. Criteria select profiles, not
individual repeated cards; grouped averages operate on all matching field values.
Drafts preserve snapshots and must be regenerated to reflect newer source data.
No arbitrary code or remote content is executed by report templates.
