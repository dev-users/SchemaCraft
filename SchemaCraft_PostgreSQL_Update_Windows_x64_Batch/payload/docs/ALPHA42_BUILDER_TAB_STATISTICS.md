# Alpha 42 Builder tab statistic hierarchy

Alpha 42 refines only the statistics displayed inside Builder tabs.

- Category and field totals are plain centered headings, not statistic tags.
- Each total keeps a prominent number and a clear Arabic label.
- Partition values remain compact tags beneath their corresponding total.
- Partition tags have larger numbers, labels, height, and spacing for easier
  scanning.
- The reconciled rows, Builder charts, history tables, and tab interactions from
  Alpha 41 remain unchanged.
