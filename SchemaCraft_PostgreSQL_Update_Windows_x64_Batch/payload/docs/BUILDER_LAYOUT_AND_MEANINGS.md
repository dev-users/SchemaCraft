# مواضع الحقول ومعاني مربعات الاختيار

- عند إضافة حقل، اختر الفئة ثم موضعه: البداية أو النهاية أو بعد حقل معيّن. يمكن تعديل ترتيب الحقل من حوار تعديله لاحقًا. يظهر اسم الفئة التي ينتمي إليها في الحوار.
- يظهر موضع الفئة الرئيسية عند تعديلها أيضًا. تبقى إعدادات الفئة الأم والحقل الذي تندرج تحته متاحة للفئات الفرعية.
- خيار «يبدأ من يمين سطر جديد» يغيّر توزيع المساحة فقط، ويحافظ على ترتيب الحقول. إذا كان الحقل يبدأ سطرًا بالفعل، لا يضيف سطرًا فارغًا. يطبّق في المعاينة وإدخال البيانات والعرض للقراءة وتصدير ملف الشخص PDF.
- يمكن إضافة شروط ظهور إلى المساحة الفارغة بالطريقة نفسها المتاحة للحقول. المساحة عنصر تنسيق، ولا تخزّن قيمة في السجل.
- تتبع أسماء البطاقات في معاينة المصمّم الإعدادات: النص المخصص مع رقم البطاقة، أو اسم الحقل المختار لتسمية البطاقة. تعرض المعاينة اسم الحقل لأن سجلًا فعليًا لم يُحدّد فيها؛ وفي إدخال البيانات يُستخدم محتوى ذلك الحقل.
- لمربع الاختيار معنيان اختياريان: معنى التحديد ومعنى عدم التحديد. عند تركهما فارغين تُستخدم «نعم» و«لا». يظهر المعنى الحالي تحت اسم المربع، وتُستخدم المعاني في عرض القيم وخيارات البحث وشروط الظهور. تبقى القيم المنطقية وقواعد الاختيار كما هي.
- عند تجاوز حقل مطلوب فارغ، يظهر التنبيه الأحمر داخل مساحة الإدخال، ويزول عند إدخال القيمة. يبقى النص الكامل وقواعد التحقق دون تغيير.

تعمل خيارات الموضع والعرض في المصمّم العام أيضًا. تُطبّق التعديلات العامة محليًا حتى الضغط على «حفظ التغييرات»، ويمكن التراجع عنها باستخدام «تجاهل التغييرات».

## التحقق

- 337 اختبار Python ناجحًا، تشمل حفظ الإعدادات وشروط المساحات وقيم مربعات الاختيار وتوزيع PDF.
- اختبارات واجهة التطبيق الحالية ناجحة.
- اختبار Chromium عبر خادم فعلي وبيانات مؤقتة: إضافة وإعادة فتح الحقول والفئات، حفظ وإعادة تحميل التصميم، الشروط، المعاني، المواضع العامة، واتجاه RTL عند أحجام نوافذ مختلفة.

إعادة تشغيل الاختبارات الجديدة: `python -m unittest discover -s tests -p test_builder_layout.py` و`node tests/test_builder_layout_browser.cjs` (مع Playwright وChromium، وتحديد `CHROMIUM_EXECUTABLE` عند الحاجة).
