# Alpha 49

Similar sidebar and panel surfaces share neutral colors, borders, spacing and corners. Truncated titles and text expose their complete text on hover. Home collapse headers use a pointer cursor.

General Builder appearance conditions resolve field names and option labels and reuse the compact schema-condition styling.

Entry labels occupy one line with ellipsis and hover text. Attachments occupy at least two grid columns: an empty control has Browse and a requested filename; a selected attachment has its filename and a delete action. Dates omit the extra formatted-date line and selector arrows. Checkbox names appear beside the checkbox.

Repeated categories reuse the Home tab styling. One card is visible at a time; the plus adds a card and each tab has a delete action. Inactive cards remain in the saved payload. Validation reveals the relevant card before focusing an invalid control, including nested cards.

Validation uses the Python regression suite, generated JavaScript syntax checks and the browser DOM workflow, including repeated-card switching/deletion and preservation of inactive-card data. Native Windows packaging is not executed in the Linux test environment.
