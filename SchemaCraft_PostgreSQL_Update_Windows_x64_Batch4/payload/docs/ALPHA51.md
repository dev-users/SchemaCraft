# Alpha 51 — connected workspace navigation

Data Entry, Builder, Search, Import and Export share a neutral page-level tab strip. The selected white tab joins the white workspace beneath it, including its side panels. No extra bordered card is introduced. Special scopes retain their separating divider. Home, Settings and repeated-record tabs retain their existing styles and behavior.

More than five page tabs enables an All Schemas control. Its modal searches visible tab names, includes special scopes, and activates the original button so existing navigation and unsaved-edit safeguards remain authoritative. Closing the selector returns focus to its trigger. Long names have full-text tooltips; buttons have visible keyboard focus, and reduced-motion preferences are respected.

Validation covers frontend assembly, JavaScript syntax, Python regressions and the browser DOM workflow including filtered schema selection. Native Windows packaging is not executed in the Linux test environment.
