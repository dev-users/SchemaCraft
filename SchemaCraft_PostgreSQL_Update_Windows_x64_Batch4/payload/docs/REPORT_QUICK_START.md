# إنشاء أول تقرير

1. افتح **التصدير ← التقارير المتقدمة ← تقرير جديد**.
2. اختر التصميم ثم **ملخص المجموعة — عدد الملفات وجدول** واضغط **إنشاء المستند والبدء**.
3. ستحصل على عنوان، جملة فيها عدد الملفات، وجدول من أول ثلاثة حقول عادية متاحة. يمكنك تعديل النص والأعمدة.
4. اضغط **معاينة**، ثم **التالي** للوصول إلى الملفات. اختر الملفات المطلوبة أو كل الملفات المطابقة.
5. تابع إلى المخرجات ثم المراجعة واضغط **فتح معاينة PDF**.
6. للإخراج النهائي، اضغط **إنشاء تقرير**. إذا لم توجد نسخة جاهزة، اختر **اعتماد المسودة والمتابعة**. اختر الملفات والمخرج، ثم **بدء الإنشاء**، وبعد اكتماله اضغط **تنزيل**.

## الحقول والحسابات داخل الجملة

اضغط حيث تريد داخل الفقرة، ثم استخدم شريط **إدراج داخل النص**:

- **إدراج حقل**: اختر الحقل من الشريط الجانبي.
- **حساب داخل النص**: تُدرج قيمة حسابية عند المؤشر ويُفتح إعدادها مباشرة. اختر عدد الصفوف، المجموع، المتوسط أو غيرها، ثم المصدر والحقل عند الحاجة.
- **نسبة داخل النص**: اضبط البسط والمقام. يمكنك التحكم في الدقة وإظهار `%` بعد القيمة.
- **تاريخ داخل النص** أو **معامل داخل النص**: أدرجها في الجملة نفسها.

مثال: «يضم التقرير [عدد الملفات] ملفًا، ونسبة الإنجاز [نسبة مئوية].»
العناصر الزرقاء تظهر أثناء التحرير فقط؛ تعرض معاينة PDF القيم العادية.
اضغط على أي عنصر أزرق، أو ركز عليه واضغط Enter، لتعديل إعداداته.

اختر **تقرير لكل ملف** عند كتابة جمل تحتوي اسم شخص أو حقوله المباشرة.
في **تقرير المجموعة**، استخدم جدولًا أو مكرر ملفات للوصول إلى حقول الأفراد؛
عدد الملفات والمجاميع يمكن إدراجها مباشرة في النص دون مكرر.

## رسائل الطرفية عند التشغيل

`Data Entry Builder is running at http://127.0.0.1:…` يعني أن خادم التطبيق بدأ.
الأسطر المنقولة عن `Gtk-Message` و`google_apis/gcm` و`on_device_model`
صادرة عن GTK/Chromium، ولا تتضمن استثناء Python أو رسالة فشل من محرك التقرير.
تحذير GPU المشار إليه يتبع خدمة نماذج Chromium المحلية، وليس محرك PDF في SchemaCraft:
https://github.com/chromium/chromium/blob/main/services/on_device_model/ml/gpu_blocklist.cc

هذه السجلات وحدها لا تحدد سبب تعثر إنشاء تقرير. إذا توقفت العملية، سجّل
رسالة الخطأ داخل نافذة التطبيق والخطوة التي ظهرت فيها. لا حاجة إلى تغيير
كلمة مرور SchemaCraft بسبب رسالة `wrong_secret` الخاصة باتصال GCM في المتصفح.
لم نغيّر إعدادات GTK أو المتصفح، ولم نخفِ الأخطاء في الطرفية.
