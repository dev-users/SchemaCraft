# Batch 7 — entry search dropdowns

Cumulative PostgreSQL release for Windows and Linux.

- Entry sidebar search dropdowns use a slightly smaller font to match their field labels.
- The value list overlays the other search fields instead of expanding the search box.
- Recorded values and counts, Ignore field, Empty and Not empty remain available; Ignore field remains the initial default.
- All previous PostgreSQL migration, verified cleanup, saved import/export, attachment, driver, Unicode-path and internal-lock changes are retained.

The updater installs the prebuilt application and new external interface assets automatically. No manual build, Node.js or Python installation is required.
