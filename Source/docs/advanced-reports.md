# التقرير المتقدم — المحرر المرئي

من **التصدير ← التقرير المتقدم** افتح **الاستوديو المرئي**. هذه هي واجهة إعداد التقارير الوحيدة. يمكن للتقرير استخدام بيانات من عدة تصاميم، حسب مجموعات البيانات التي تختارها.

## 1. صمّم المستند

ابدأ بتخطيط جاهز: **ملخص مع مؤشرات**، **جدول ملفات** أو **ملف تفصيلي**. اختر التصميم ووحدة الصف (ملف شخص أو بطاقة متكررة)، فيربط المحرر البيانات والكتل تلقائيًا. يمكن أيضًا البدء بالكتل الافتراضية وتخصيصها.

- اسحب كتلة من **مكتبة الكتل** إلى علامة **+** بين عناصر الصفحة.
- اضغط اسم الكتلة لإضافتها بعد الكتلة المختارة، أو استخدم **+** لإدراجها في موضع معيّن.
- اسحب مقبض الكتلة لنقلها. أزرار أعلى وأسفل بديل متاح دون سحب؛ وأزرار التراجع والإعادة تستعيد الترتيب.
- اضغط كتلة لعرض **إعدادات الكتلة المختارة**. يتحدث نصها وشكلها على الصفحة أثناء تعديل الإعدادات.
- الكتل المتاحة: عنوان، نص، غلاف، فهرس، فاصل صفحة، قيمة حقل، جدول، قسم متكرر، مؤشر ورسم مؤشرات.

معاينة التصميم تعرض البنية والأماكن المحجوزة. الرسوم فيها توضيحية؛ القيم الفعلية تظهر بعد اختيار الملفات وإنشاء التقرير.

## 2. اربط البيانات

لكتل الحقول والجداول والأقسام المتكررة زر مباشر لإعداد مصدر البيانات. في خطوة **البيانات** يمكن إضافة مجموعات أخرى؛ أعط كل مجموعة اسمًا واضحًا واختر تصميمها ووحدة الصف.

افتح **شروط البيانات وترتيبها — اختياري** لتصفية الصفوف أو ترتيبها. شروط البطاقة المتكررة تطبق على البطاقة نفسها. المجموعات التي تشترك في اسم مجموعة الملفات تستخدم IDs نفسها عند التطبيق؛ غيّر الاسم عندما تريد اختيار ملفات مختلفة.

اختر أعمدة الجدول ورتبها، ويمكن تفعيل إجمالي الأعمدة الرقمية. في القسم المتكرر، أدرج الحقول في النص من القائمة؛ يمكن بدء صفحة مستقلة لكل صف.

## 3. عرّف المؤشرات مرة واحدة

تدعم المؤشرات المجموع والمتوسط والوسيط وعدد القيم وعدد الملفات والقيم المختلفة والحدين الأدنى والأعلى. يمكن استخدام المؤشر في النص أو كتلة مستقلة أو رسم أعمدة/خط/دائرة.

يمكن إنشاء معادلة من مؤشرات أخرى: اضغط أسماءها لإدراج رموزها ثم أضف العمليات الحسابية. يعتمد التجميع على الصفوف المطابقة لشروط مصدر البيانات. القسمة على صفر تظهر كقيمة غير محسوبة.

## 4. طبّق وراجع وصدّر

انتقل إلى **التطبيق والتحديث** أو اضغط **معاينة التقرير**. أدخل IDs أو اخترها من الملفات، ثم **إنشاء من القالب الحالي**.

- **تفسير الرقم** يعرض الحساب والقيم المساهمة والمؤشرات التي يعتمد عليها.
- **فحص الصفوف والقيم** يعرض المصدر ويمكن تعديل قيمة في المسودة مع سبب؛ تتحدث الحسابات والكتل المرتبطة.
- **تحرير هذه النسخة** يتيح تعديل النص الناتج مع توثيق السبب. السجلات الأصلية لا تتغير.
- **تحديث البيانات مع حفظ التعديلات** يقارن المصدر الجديد بالمسودة، ويعرض التعارضات للاختيار بين التعديل اليدوي والمصدر الجديد قبل الاعتماد.
- **حفظ المسودة** يحفظ هذه النسخة للعودة إليها. **حفظ وصفة تشغيل** يحفظ القالب واختيارات الملفات لتوليد تقرير جديد من البيانات الأحدث؛ الوصفة لا تتضمن التعديلات اليدوية.
- يمكن تشغيل عدة وصفات وإخراج PDF مستقل لكل منها داخل ZIP، حتى 20 وصفة في العملية.

إعدادات الصفحة تشمل الاتجاه وحجم الخط واللون والرأس والتذييل. **معاينة PDF** تعرض الصفحات الفعلية، بما فيها أرقام الفهرس. ثم استخدم **تصدير PDF** لاختيار مكان الحفظ.

## القوالب والتوافق

يظل القالب محفوظًا بصيغة **.md**، مع تعريف المستند المرئي داخل الملف. استخدم قائمة **خيارات القالب** لإنشاء قالب جديد أو نسخة مستقلة أو تنزيله أو استيراده أو حذفه. المسودات المحفوظة ووصفات التشغيل متاحة في خطوة التطبيق.

القوالب النصية القديمة لم تُحذف أو تُحوّل تلقائيًا؛ تظل ملفاتها محفوظة. واجهة هذا الإصدار تستعرض القوالب والمسودات المرئية فقط، واستيراد .md يتطلب قالبًا صادرًا من المحرر المرئي. نقل القالب بين مساحات عمل مختلفة يستلزم مراجعة روابط التصاميم والحقول.

## Report page and dialog polish

- Refined the Advanced Report landing page, reusable template cards, and direct entry points for drafts and recurring recipes.
- Consistent RTL dialog headings, step navigation, save status, source setup, inline validation, and responsive spacing. Validation retains entered values.
- Template saving rebinds editing controls to the saved model, so subsequent edits persist correctly. Cancelling template switches restores the selected template. Undoing back to the saved document clears the unsaved-template warning.
- Reopening the same data source preserves filters, columns and totals without creating duplicate datasets.
- Ctrl/Cmd+S saves the draft in the application step and the template elsewhere, even after preview rebuilding; nested dialogs retain their own keyboard behavior.
- The application step identifies missing block settings and distinguishes an older generated preview from changes awaiting regeneration.


## قيم متعددة داخل الجملة

1. أضف كتلة **نص وتعليق** أو عنوانًا أو غلافًا، واكتب الجملة.
2. ضع المؤشر بين الكلمات ثم اضغط **إدراج قيمة داخل النص**.
3. اختر حقلًا من مصدر بيانات، أو حسابًا محفوظًا، أو تاريخ التقرير. داخل القسم المتكرر يمكنك اختيار حقل الصف الحالي.
4. كرر الإدراج في الجملة نفسها، ثم أنشئ التقرير من خطوة التطبيق.

مثال: «المستفيد ⟦الاسم⟧ لديه ⟦عدد الطلبات⟧ طلبات، بقيمة إجمالية ⟦المجموع⟧».

القيمة الفردية تتطلب صفًا مطابقًا واحدًا. إذا أعاد المصدر صفرًا أو عدة صفوف، يظهر خطأ واضح بدل اختيار شخص عشوائيًا. استخدم مجموعة باسم «المستفيد» وحدد لها ID واحدًا، ومجموعة باسم «الإحصاءات» لبقية الملفات. لكل قيمة زر لعرض مصدرها في المعاينة. تبقى التعديلات اليدوية قابلة للمراجعة والتحديث.

## عدّ الملفات والشروط الخاصة بالحساب

من **المؤشرات** اضغط **+ عدد الملفات**، ثم اختر البيانات. لا يلزم اختيار حقل لعدّ الملفات أو الصفوف.

- **عدد الملفات دون تكرار**: كل ID مرة واحدة، حتى مع عدة بطاقات مطابقة. في مصدر البطاقات، يُحسب فقط الشخص الذي لديه بطاقة مطابقة واحدة على الأقل.
- **عدد الصفوف / البطاقات**: كل صف مطابق مرة واحدة.
- **عدد القيم غير الفارغة**، **عدد القيم الفارغة**، **عدد القيم المختلفة**: تُحسب على الحقل المختار. الصفر قيمة موجودة وليس خلية فارغة.
- **المجموع والمتوسط والوسيط والأدنى والأعلى**: تستخدم القيم الرقمية غير الفارغة. الحقل غير الرقمي المستخدم في حساب رقمي يوقف العملية برسالة واضحة.

افتح **شروط هذا الحساب فقط** لإضافة شرط أو أكثر مع **كل الشروط AND** أو **أي شرط OR**. تُطبّق هذه الشروط بعد شروط المجموعة، ولا تغيّر بقية المؤشرات. يمكن عمل مجموع مشروط أو متوسط مشروط بالطريقة نفسها. شروط البطاقة الواحدة لا تتوزع على بطاقات مختلفة.

لحساب نسبة، أنشئ مؤشرًا للعدد المشروط وآخر للعدد الكلي، ثم معادلة: `metric1 / metric2 * 100`، مع اللاحقة `%`. تظهر القسمة على صفر كقيمة غير محسوبة. **تفسير الرقم** يعرض شروط المجموعة والحساب وعدد الصفوف والملفات المطابقة والمراجع المساهمة.

## كل الملفات بدل إدخال IDs

في **البيانات ← الملفات التي تدخل في التقرير** اختر **كل ملفات هذا التصميم**، وحدد إن كنت تريد تضمين المؤرشفة. لا تحتاج هذه المجموعة إلى IDs في خطوة التطبيق. الإنشاء والتحديث ووصفات التشغيل تقرأ الملفات الأحدث. الحد 5000 ملف/صف لكل مجموعة، مع حد حجم المسودة؛ اختر نطاقًا أصغر أو قسّم التقرير عند تجاوز الحدود. خيار IDs المحددة يبقى متاحًا حتى 500 ID لكل مجموعة.

## الأخطاء والتوافق

أخطاء الحساب والتوليد والتصدير تظهر في حوار واضح فوق الحوار النشط، مع السبب وزر العودة للتصحيح، وتبقى رسالة بارزة في الاستوديو. بعد إصلاح السبب يمكن إعادة المحاولة دون إعادة بناء المستند المفتوح.

تبقى القوالب `.md` متوافقة؛ تعريف المستند المنظم داخلها يحفظ القيم المضمنة والشروط الجديدة. لا يلزم تغيير صيغة الملفات للاستفادة من هذه الميزات.
