# Batch 6

Cumulative prebuilt PostgreSQL-only release for Windows and Linux.

- Application/updater coordination remains inside the application folder. An operating-system gate protects atomic publication of verified program files.
- Preconfigured record-search fields show recorded values and their counts, plus Ignore field (the initial default), Empty and Not empty in one picker.
- Previous verified migration, cleanup, saved import/export preservation, attachment, driver and Unicode-path fixes are included.

The updater installs the newly built executable automatically; no local build or Node.js installation is required.
